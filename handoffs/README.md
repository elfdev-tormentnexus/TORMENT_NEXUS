# Handoffs

Working notes passed between sessions and between assistants while building
this project. They are kept because they record *why* decisions were made and
what was measured rather than assumed — including the approaches that failed.

**They are not documentation.** They are dated, they go stale, and they
describe the tree as it was on the day they were written. Nothing here is a
current statement about how TORMENT_NEXUS works.

For that, start at the [README](../README.md), or:

| You want | Read |
| --- | --- |
| To install it | [Installing on Windows](../docs/INSTALL_WINDOWS.md) |
| What works and what does not | [Capabilities and limits](../docs/CAPABILITIES_AND_LIMITS.md) |
| How it is built | [Architecture](../docs/ARCHITECTURE.md) |
| What changed and when | [Changelog](../CHANGELOG.md) |

Anything in this directory that turned out to matter has already been moved
into `docs/` and rewritten as documentation. What remains is the reasoning
trail behind it.
