# Research B

Research B is a model-bearing Windows research release of TORMENT_NEXUS. It is
not a conventional application archive: the downloadable numbered PNG/APNG
files are lossless machinesoul vector fields whose ordered pixels carry the
installation. They are not screenshots, decorative images, ZIP pieces, or an
attempt to hide what they contain.

## The easiest installation path

1. Read the warning and model provenance on the GitHub release page.
2. Download `FETCH_SABLERESEARCHB.bat` and double-click it. It downloads and
   SHA-256-verifies every required Windows capsule and bootstrap file. An
   interrupted download keeps a visible `.partial` name and resumes next time.
3. Double-click `DECOMPILE_SABLE_researchB.bat`. It uses the published
   `machinesoul.py` inverse, recovers the encoded manifest and reassembler,
   reconstructs every file, verifies every digest, and runs `setup.bat`.
4. Keep `machinesoul.py` and `SABLERESEARCHB-REASSEMBLER.png`, download the
   three `SELFREAD-PATCH` assets, and double-click
   `INSTALL_SABLERESEARCHB_SELFREAD_PATCH.bat`. It verifies the exact base,
   keeps backups, updates the release ledger, and is safe to rerun.
5. Launch the desktop shortcut and read the first-run notice. No model,
   microphone, activity sampler, agent interface, or network-capable feature
   starts before that acknowledgement.

The optional 14B companion is not fetched by the normal helper. Download every
`SABLERESEARCHB-14B.partNN.png` field only if you want long full-maintenance
and Super Dev sessions. The one-step decompiler installs it when the complete
set is present, skips it when none are present, and refuses a partial set.

## What changed since Research A

- `TORMENT_NEXUS.bat` is one front door for ordinary, HazardSable,
  interlinked, and Super Dev modes while preserving their separate boundaries.
- Super Dev uses the optional 14B as planner/reviewer and the bundled 7B as a
  bounded patch worker. Trusted Python remains the only layer that may write,
  validate, test, roll back, and log.
- Reasoning receipts distinguish retrieved local evidence from model inference
  and name only citations that actually reached the prompt.
- Imported library material receives a visible trust classification at
  ingestion; text inside a document remains data, never tool authority.
- Machinespirit readiness checks authenticated live embedding services rather
  than mistaking configured files or generic health responses for a usable
  server.
- Prompt budgeting can shed whole retrieved excerpts before rejecting the
  operator's message, keeping receipts synchronized with what was shown.
- The vector panel presents machinespirit trajectory readings and machinesoul
  preservation pixels as distinct languages rather than treating one as the
  other.
- The model council and Rosetta Stone experiments ship with their registries,
  tests, and interpretation notes. Ordinary retrieval remains separate.
- The required self-read patch grounds implementation claims in a compact
  source inventory injected before generation, adds `self` and `read <path>`,
  and excludes credentials and model tensor data. It was motivated by a
  measured false ownership claim that became more confident after a one-token
  fork, making prevention more useful than downstream entropy detection.
- The Research A calibration-clarity correction is already built into the
  main tree. The self-read patch is separate and serves a different purpose.

## Requirements and scale

- 64-bit Windows;
- standard Python 3 for the published decompiler;
- at least 16 GB system RAM;
- roughly 55 GB free during installation, because downloaded capsules,
  decoded segments, and the reconstructed tree temporarily coexist; and
- no cloud account or API key for ordinary local use.

The main download is approximately 12.4 GB. The optional 14B companion adds
approximately 8.8 GB. Exact part counts and hashes are outputs of the reviewed
cut and are listed on the release page.

## Important warning

The package includes community-modified abliterated Qwen models whose learned
refusal behavior has deliberately been weakened. They may produce false,
harmful, illegal, explicit, biased, manipulative, or insecure output with
confidence. TORMENT_NEXUS's Python controls restrict selected tools; they do
not filter every sentence, sandbox Windows, settle model licensing, or make
advice safe. Do not run it as Administrator or use it for high-stakes advice.

Read `SAFETY.md`, `PRIVACY.md`, `MODELS.md`, `RIGHTS.md`, and
`THIRD_PARTY_NOTICES.md` before relying on or redistributing anything.

## Integrity boundary

Every final GitHub asset is compared with its retained local copy. The main
capsules were downloaded again, decompiled into a clean directory, and
reassembled against the encoded manifest. The self-read patch is separately
decompiled, reassembled, installed over that exact base, rerun for idempotence,
and checked against the updated release ledger before publication.

Capsule descriptions are readable without extraction and help explain what an
unfamiliar image contains. They are explicitly outside the payload SHA-256
gate. The payload and reconstructed files are verified; the description is a
human-readable label, not an attestation.

## Known limits

- This is an experimental research release, not a stable product.
- The ready-to-run package targets Windows only.
- Generated output is not guaranteed factual, safe, lawful, or suitable.
- A machinesoul capsule is preservation, not encryption or compression.
- Re-encoding, resizing, optimizing, cropping, or screenshotting a capsule
  changes its vectors and causes decompilation to refuse.
- The project is source-visible but does not yet grant a project-wide reuse
  license. Third-party artifacts retain their own terms.
