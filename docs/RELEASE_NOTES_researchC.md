# Research C

Research C is a model-bearing Windows research release of TORMENT_NEXUS. Its
theme is measured uncertainty without pretending uncertainty is truth:
logprob observations remain metadata, trusted code remains the authority for
actions and source facts, and null/refuted experiments ship beside positive
ones.

## What changed since Research B

- The 14B planner, 7B patch drafter, and 4B durable-memory extractor can record
  top-two token uncertainty on the spans that matter. The privacy-safe sidecar
  contains digests, sampler/model binding, numeric metrics, bounded outcomes,
  and timing—never prompt, reply, source, or memory text.
- An offline Research C report compares fit and holdout data, reports false
  refusals with compute avoided, and includes Wilson intervals, exact paired
  McNemar tests, Wald sequential decisions, compression screens, and a
  rate–distortion frontier. It cannot install a threshold into Sable.
- Source existence, line/byte counts, Python definitions, Markdown outlines,
  and retained-authorship questions are checked by trusted code and returned
  with a path/hash receipt. The director no longer gets to mint those facts
  from a filename.
- The source manifest now uses real displayed-line counts, labels directory
  aggregates and recency honestly, reads the edit logs that the editing
  engines actually write, and excludes audit handoffs from product recency.
- Stable self-knowledge moves before the live clock in the runtime prompt, so
  the largest reusable prefix is no longer invalidated before the static
  source block.
- Windows sessions ask the OS to keep the display/audio path awake. If an
  endpoint still disappears, visualizer capture re-enumerates the default
  output and local playback retries the same track from the saved frame.
  SoundCard cleanup `S_FALSE` no longer hides the primary capture failure.

## What the experiments found

The completed paired probes are preserved under
`handoffs/researchc_evidence_2026-07-30/`.

- Grounding caused reliable prompt-context/pathname misattribution on selected
  per-file questions, including 8/8 copied directory totals versus 8/8
  ungrounded refusals.
- Agreement with a nonexistent class and false authorship occurred equally in
  grounded and ungrounded conditions (6/6 each). Those are base-model biases,
  not evidence that the manifest caused them.
- Equal-length gzip separated one prompt family and failed to generalize.
- A two-request reverse-order screen changed compliance but did not establish
  quantum contextuality or a law-of-total-probability violation.
- Top-two candidate data was the measured compromise: about 0.057 seconds
  paired median overhead and roughly 13× response payload in the local
  benchmark. Top-ten offered no release benefit for its larger payload.

## Boundaries and unfinished validation

Research C does not enable an uncertainty refusal threshold, automatic
small-to-large routing, a compression truth score, density-matrix memory, or a
contextuality claim. The required labelled fit/holdout data does not exist.
All deterministic write, capability, regression, and memory rules remain in
force.

Audio recovery has automated endpoint simulations and regression coverage, but
the physical Windows matrix—sleep/wake, lock/unlock, output switching, and
HDMI disconnect/reconnect—must still be completed before calling it
hardware-validated.

The package still includes community-modified abliterated Qwen models. They
can produce false, harmful, illegal, explicit, biased, manipulative, or
insecure output with confidence. Python controls selected actions; they do not
make generated advice safe or truthful. Do not run as Administrator or use the
assistant for high-stakes decisions.
